# Scoping: redesign, richer results and an interactive network

- Date: 2026-11-10
- Workflow: Web app (full)
- Next command: /bio-tickets

## Request

Make the live site as engaging as the 2021 site (purple header, colour chips, labelled cards, example buttons) while keeping the newer content, and turn the network picture into a much nicer clickable object.

## Findings

### Facts
- Old site features (screenshot, 2021 release): header with nav and dark toggle, four example buttons, query panel and per-match panels with three cards (Phenotype as grouped bullets, Other metadata with PMID links, is_a and product, Match details), colour chips.
- New site today: plain header, empty box, about 200 words of caveats above results, phenotype as one string, no PMID, is_a or product, small non-interactive picture (docs/network-view.md).
- Phenotype shapes in graph-2026.11.09 (plain Python count): NCBI 7299 "confers resistance to subclass X/Y", CARD 4339 "... drug class: a,b" and 1507 "... antibiotic: a,b", 1260 CARD additional phenotypes "... drug class: ...", ResFinder 2589 "confers resistance to X, Y". No commas inside parentheses.
- Metadata in the data: PMID on 2262 entries, is_a on 5971, product on 7299.
- The old example NG_050598.1 is not an entry id in this release (it is a duplicate allele id), so examples need entries that exist.

### Risks
| Risk | Mitigation |
| --- | --- |
| Splitting phenotype changes meaning | Recompose test on every entry; NCBI kept as one item; verbatim fallback |
| Colour chips fail contrast or rely on colour | Computed contrast on every pair; chips carry text labels; no literal colours |
| A match of a match read as a match of the query | Second-step nodes and edges styled and labelled differently; caption states it |
| Interactive picture inaccessible | Nodes are focusable buttons with names; list stays an equivalent; keyboard-only Playwright path |
| Big restyle breaks the accessibility and egress checks | Existing contrast, keyboard, swap and egress tests run on every ticket |
| Click-to-navigate floods history | One pushed entry per click; slider and database filter keep replaceState |

### Open questions
| Question | Owner | Blocking? |
| --- | --- | --- |
| Palette values (start from the 2021 site, refine so every pair passes) | implementer, owner reviews mock-ups | No |
| Maximum expanded nodes before the picture is capped | implementer, owner reviews | No |

## Cost of being wrong
Presentation and wording only; no result changes. The scientific risks are honesty of wording (phenotype pieces, second-step matches), covered by tests and review.

## Decisions
- ADR 0005: redesign and interactive network (proposed)

## Out of scope
New data or releases, a backend, analytics, Canvas, BSB branding, changing the match rule.
